# 愤怒的小鸟（HTML5 Canvas 单文件版）

一个可以直接双击打开的《愤怒的小鸟》小游戏：10 种小鸟、9 个难度递增的关卡，**动态星空夜景** 背景 + **3D 质感** 的小鸟与猪，纯手写 2D 物理引擎，无任何外部依赖、无网络请求、无图片音频素材（音效由 WebAudio 实时合成）。

**直接玩：双击 `愤怒的小鸟.html`**（推荐 Chrome / Edge / Safari，手机浏览器也支持触屏）。

## 开始流程

1. **首页**：红红在前，其余 9 只小鸟跟在后面一起冲向猪群（速度线、尘土、猪在抖动），底部只有一个「开始游戏」按钮
2. 点「开始游戏」→ **选择关卡**（9 张卡片，显示星级与最高分）
3. 点关卡卡片 → **出战介绍页**：前后左右都还是这一关的真实场景，中间列出本关出战的每一只小鸟、它的技能名和一句话说明
4. 点「开始战斗」才真正开始；「返回选关」可以退回去

## 玩法

- 按住弹弓上的小鸟往后拖，松手发射；拖动时会显示预测弹道（白色虚点）。
- 小鸟飞行途中**点击屏幕**（或按空格）触发它的技能。
- 待发的小鸟会**在弹弓左边排队**，每只都有自己的等待小动作；上一只飞出后队列整体向前挪一格。
  - **红红**：在排队或蹲在弹弓上时都在吃糖果，**蓝 / 黄 / 白**三种糖一颗吃完换下一颗，一直轮不到它就一直换
  - **飞镖黄**：气得原地蹦跳，每次起跳脚边会有星光炸开并跟着它
  - 蓝弟弟抖个不停、白姐姐一伸一缩、气球鸟轻轻飘浮、回旋鸟一蹦一蹦、大块头慢慢呼吸……
- 打掉所有绿猪即可过关；剩余小鸟每只额外 +10000 分。
- 快捷键：`R` 重玩本关，`M` 静音，`Esc` 返回选关。

星级目标按关卡理论上限动态计算（约 46% / 63% / 80%），最高分与星级存在浏览器 localStorage 里，通关解锁下一关。

## 目录结构

```
愤怒的小鸟.html      # 成品：单文件游戏（构建产物，双击即玩）
src/physics.js       # 2D 刚体物理引擎（矩形 + 圆形，冲量法 + 顺序冲量 + 热启动）
src/game.js          # 游戏逻辑、渲染、音效、关卡数据
src/index.html       # HTML 外壳模板
tools/build.mjs      # 把 physics.js / game.js 内联进单文件 HTML
tools/test-physics.mjs  # 物理引擎测试（稳定性 / 性能 / 碰撞）
tools/smoke.mjs      # 无头冒烟测试（桩 canvas 跑完整游戏流程）
tools/balance.mjs    # 关卡平衡性扫描（发射角度 × 破坏效果）
```

## 开发

```bash
node tools/build.mjs        # 重新生成 愤怒的小鸟.html
node tools/test-physics.mjs # 物理测试
node tools/smoke.mjs        # 游戏流程测试（10 种技能、9 关、爆炸、渲染）
node tools/balance.mjs      # 平衡性数据（每关首发能打掉几只猪）
```

调试参数（加在 HTML 地址后）：

- `?level=0` 直接进入第 1 关（下标从 0 开始，最多 `?level=8`）
- `?level=4&fire=-96,26&steps=180` 自动发射一次并快进 180 帧，便于截图
- `?screen=levels` / `?screen=won` 直接打开选关 / 结算界面
- `?screen=levels&unlock=1` 解锁全部关卡（仅调试用）

## 实现要点

- **动态星空**：240 颗星按三层时间相位独立闪烁（大星带十字星芒）；斜向银河带、带环形山的月亮 + 光晕、随机流星（4.5–11 秒一发）、地面附近的萤火虫光点；远山/近山/树丛是夜色剪影，近山脊有月光描边。
- **3D 小鸟**：球面径向渐变（光源固定在左上）+ 环境光遮蔽 + 脂肪高光 + 左上边缘光 + 右下夜色冷反射；眼睛有眼窝阴影、高光点与双目反光；喙分上下两片带高光和分界线；飞行时脚下有随高度变化的地面投影。尺寸小于 16px 的图标会自动省略部分图层以省性能。
- **3D 猪**：同样的左上光源球面渐变，加立体耳朵（内外两层渐变）、凸起的 3D 猪鼻（凹陷鼻孔 + 上缘反光）、可眨眼的眼球；铁皮头盔是带帽檐、铆钉和高光的金属半球，猪王是带宝石的金冠；地面投影不随身体翻滚旋转。
- **排队动画**：10 种小鸟各有独立的等待动作（呼吸 / 摇摆 / 抖动 / 拉伸 / 浮空 / 跳跃），相位按队列序号错开；上弓时队列用 0.2 秒缓动整体前移一格。红红额外挂了一条「吃糖」时间轴：3.6 秒一颗，出现 → 拿着晃 → 咬掉 → 换色（蓝/黄/白循环）；飞镖黄的跳跃会把星光画在身体之前，让光点从脚边透出来。
- **冲刺星光**：飞镖黄加速时在尾部按 28ms 间隔喷出四角星粒子，粒子不受重力、只会飘散，配合原有的速度残影线。
- **首页与介绍页**：首页是纯程序化动画（红红主视觉 + 9 只僚机 + 速度线 + 抖动猪），只有一个按钮；介绍页会先 `buildLevel` 把真实关卡搭在背后，面板只做遮罩，点「开始战斗」直接进入已落定的场景。
- **物理**：SAT 求分离轴 + 参考面裁剪生成最多两个接触点；顺序冲量求解器带累积冲量与跨子步热启动，三层结构可以长时间稳定不抖；每帧 3 个子步 × 12 次迭代，40 个刚体时约 0.1ms/帧。
- **伤害**：按撞击法向冲量与相对速度换算伤害；小鸟撞击全额伤害，物体互撞只算 58%，避免"碎块自己滚一圈就把猪全砸死"。
- **技能**：冲刺改速度、分裂加刚体、爆炸按半径衰减冲量与伤害、寒冰把附近方块冻脆并挂霜、落雷对竖直条带逐个结算、浮空期间抵消 94% 重力。
- **防卡关**：被挤到弹弓左侧（射程外）或掉出场地的猪会自行消失，不会出现打不到的猪。
- **画面**：全部矢量绘制，木纹 / 石头斑点 / 玻璃高光 / 裂纹按固定种子生成，破坏程度越高裂纹越多；猪王有王冠、铁皮猪有钢盔。
